# Servo Studio 已确认设计

用户确认 Rust 网页包位于 microduck 内，设备访问统一通过 robotd。用户选择手动摆成标准姿态后采集零位；调零页固定显示标准参照，提供回归零位、将当前姿态设为零位。调试支持卸力、低 P 保持和柔顺跟随。软件标定沿用 /etc/robot/feetech1910.json，不改舵机 EEPROM 中位。

后续补充：身体 IMU 单独按钮标定，鸭子在桌面直立静止；头部 IMU 是另一条数据流，不混用。静态水平校正无法确定安装前向，需要已确认的安装方向。

实现选择：独立 studio crate + robotd 控制线程内的调试状态机。原提案“网页服务独立接管串口”已被用户明确否决；未实现该方案。允许开机使用 robotd --servo-debug 绕开完整运动标定和 IMU 依赖，但不启动正常策略。

实际接口、状态和边界唯一维护于 [机制说明](../../design/servo-studio.md)，操作命令维护于 [包说明](../../../studio/README.md)。
