用户已确认：在控制网页增加麦克风、扬声器、摄像头配置，不添加重复开关；每个设备选择「无」即可停用对应通路。保留「硬件」名称及既定组件、配色和尺寸。

## 实现范围

- 独立保存录音和播放设备，扬声器音量，以及摄像头节点和现有四档画质。
- 使用主控枚举的设备列表；允许手动填写未被枚举出的有效设备标识。
- 使用现有 TOML 配置编辑机制原子保存，不在浏览器中模拟设备配置。
- 「无」必须在运行端真正禁止打开对应设备；摄像头无设备时不回退到测试图。
- 保留既有命令行覆盖约定，并在网页锁定被启动参数覆盖的摄像头设置。
- 明确保存值和重启生效范围，不把未验证的配置显示为已在硬件生效。
- 音频设备树适配、录音试听和测试音不在本次范围；缺少声卡明确提示系统侧尚未提供设备。

## 工作步骤

1. 检查并扩展参数模型、验证、注册表及持久化测试，约定独立设备禁用语义。
2. 新增读取/保存外设 IPC，枚举 ALSA 录放设备和视频节点，更新所有协议路由消费者。
3. 运行端消费设备配置；验证「无」不会触发播放、采集或摄像头打开。
4. Studio 接入接口，在硬件配置中分区显示三个设备，使用标准 shadcn 组件和统一尺寸。
5. 运行参数、协议、运行端相关测试和前端构建，并在隔离模拟实例验证保存与刷新。

后端参数/IPC/运行端与 Studio 前端分别处理；接口确定后整体验证。保留当前未提交的串口单框、指针样式及根仓库硬件资料。
